# ClearPoints Design System Master File

> **LOGIC:** When building a specific page, first check `design-system/clearpoints/pages/[page-name].md`.
> If that file exists, its rules **override** this Master file. Otherwise, follow the rules below.

**Project:** ClearPoints
**Category:** Premium / Trust & Authority (fintech-adjacent travel)
**Direction:** Clean, credible, premium. Minimal layout with a restrained Aurora accent. NOT heavy glassmorphism. Generous whitespace, confident type, calm motion. We sell trust in numbers, so the UI must read as precise and honest.

---

## Brand Voice

- Plain, confident, specific. We explain points value like a smart friend who is good with money.
- No hype, no exclamation spam, no em dashes in user-facing copy.
- Numbers are the hero. Always show the cash reference next to the points cost so value is obvious.
- Name: **ClearPoints**. Tagline: "See what your points are really worth."

## Typography (Google Fonts, loaded via next/font)

- **Display / Headings:** `Sora` (600/700). Tight tracking on large sizes.
- **Body / UI:** `Inter` (400/500/600).
- **Numeric / tabular:** `Inter` with `font-variant-numeric: tabular-nums` for all points, taxes, cpp, and percentages so columns align.

Scale: 12 / 14 / 16 / 18 / 20 / 24 / 30 / 36 / 48 / 60.

## Component Specs

### Buttons
- **Primary:** gold `--color-cta` background, white text, weight 600, radius 8, padding 12x24, transition 200ms. Hover: `translateY(-1px)`, slight darken (no layout shift). Always `cursor-pointer`. Visible focus ring `--color-secondary`.
- **Secondary:** transparent bg, `--color-primary` text, 1px border `--color-primary`. Hover: bg `--color-background`.
- **Ghost:** text only, `--color-secondary`, underline on hover.

### Cards
- White surface, 1px `--color-border`, radius 12, shadow sm, padding 24. Hover (interactive only): shadow md + `translateY(-2px)`. No scale that shifts layout.

### Inputs
- 1px `--color-border`, radius 8, padding 12x16, font 16 (prevents iOS zoom). Focus: border `--color-secondary` + 3px ring at 20% opacity. Labels always present.

### Deal card (product-specific)
- Top row: route `ORIGIN -> DEST` in Sora 18, cabin chip on right.
- Hero number: points cost (tabular), with cash reference and `cpp` value badge beneath. Discount shown as a colored pill (positive green, neutral gray, warning amber).
- Footer: transfer path (program chips with ratio) and a "How to book" disclosure.

### Value badge rules
- `cpp >= 1.8` -> positive green "Great value".
- `1.0 <= cpp < 1.8` -> neutral "Fair value".
- `cpp < 1.0` -> warning amber "Below cash".

---

## Motion
- Calm: 150-300ms ease for UI, up to 500ms for the Aurora hero shimmer only.
- Respect `prefers-reduced-motion`: disable the aurora animation and all transforms.

---

## Anti-Patterns (Do NOT Use)
- No emojis as icons. Use Lucide SVG icons.
- No fares or points generated by a model. Every number traces to seeded/provider data.
- No client-only premium gating. Gate server-side off `subscription_tier`.
- No low-contrast text, no invisible focus, no layout-shifting hovers, no instant state changes.
- No imitation of any existing points-deal site palette, mascot, copy, or layout.
